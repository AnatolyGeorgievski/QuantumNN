## Вердикт

**Ступень глаза — годная дымовая лесенка.** Не production ggml-op, и он это не маскирует.  
Correctness на заявленных кейсах — да. Качество — **учебно-инженерное, выше мусора**, с дырами ниже.

## Что хорошо

| место | зачем ценить |
|-------|----------------|
| `im2col_tile` | узкий контракт (stride=P, без pad); CPU-эталон совпадает; P=14 и 16 закрыты |
| `patch_emb` | честно «не полный mmproj»; печатает ассемблерный лист; порог 1e-3 под float GEMM осознан |
| `pool_2d_tile.cl` | subgroup reduce в духе ggml; на A770 avg s==k pad=0 — OK (k=2/4/8) |
| стиль check_* | короткие скрипты, exit-код, seed=0, без лишних зависимостей кроме pyopencl/numpy |
| зёрна `nil_grain` / fma | понятный probe ICD (fp16 ifdef в сводном файле) |

## Замечания (по тяжести)

### 1. `pool_2D_avg` — лишняя работа, не баг чисел

Хост ставит `local=(PREFERRED_WG_MULTIPLE,1,1)`. На A770 preferred=**64**.  
Subgroup меньше WG → несколько subgroup считают **один и тот же** tile и пишут один `dst` (гонки на запись одного значения). Числа сходятся; FLOPs×N зря.

**Контракт правки:** ты ([[nil]]) ставишь `local_size = get_max_sub_group_size()` (или `intel_reqd_sub_group_size` + LWS=тому же), не preferred×64.

### 2. `half_fma.cl` vs `nil_grain.cl`

В `nil_grain` half под `#ifdef cl_khr_fp16`.  
В отдельном `half_fma.cl` ядро **вне** ifdef — на ICD без fp16 сборка падает. Дубль `float_fma` в двух файлах.

### 3. `warp_sg16.cl`

Probe: читает `data[i+ix]` при `i<512` без проверки длины буфера; `as_half2` по float-ячейкам. Для зерна ок, в общий suite без оговорки размера — нельзя.

### 4. Документация-призраки

`check_patch_emb_op.py` ссылается на `opencl/отладка-тензорный-ассемблер.md` — в дереве **нет**.  
Фикстуры `graph-a770*.txt` — дамп mtmd (n_nodes 1197), не воспроизводимый скриптом из `hq-eye`.

### 5. Не ggml / не Whisper

`im2col_tile` ≠ общий `GGML_OP_IM2COL` (нет kernel/dilation/pad, один канал в шаге1).  
`gemm_nt` — наивный O(MEK), только дым. Это норма для лесенки; в llama backend не переносить как есть.

### 6. Мелочи

- `ne01` в `pool_2D_avg` не используется.  
- Нет `-h` описания устройства при `-d` out of range → IndexError.  
- Табы в `.cl` зёрен vs пробелы в pool — косметика.
