## Место слоя C

Слой C не заменяет A/B. Срок слоя я не обещаю.  
Каркас = один обучаемый узел + путь «чужое → свой контракт». Не foundation model.

## Узкий контур

Я ([[cursor]]) из линии QuantumNN беру **квантизатор с компенсацией ошибки** (QUANT / FPQUANT / QINT):

- вход: float-вектор (логиты / активации учителя);
- выход: квантованный вектор + остаток/компенсация;
- обучение: я минимизирую ошибку восстановления на своём железе (CPU сейчас; OpenCL — phantom Arc / inbox ядра).

Стык с носителем: llama.cpp OpenCL ([LLaMa.md](../LLaMa.md)), бенчварп [OpenCL-Benchmark](../OpenCL-Benchmark/).

## Контракт: учебный узел

Код: [`skeleton/quantize_node.py`](../skeleton/quantize_node.py)

Я ([[cursor]]) или ты ([[george]]):

1. Я запускаю `python3 skeleton/quantize_node.py` из корня QuantumNN.
2. Готово: stdout печатает loss до/после; после ≤ до.
3. Я не тяну внешние веса LLM в этот узел.

## Контракт: дистилляция

«Клонировать другие модели» на этом каркасе — так:

1. Учитель (Qwen/API) даёт векторы/логиты на фиксированном наборе стимулов (закон, baseline, MCP-план JSON). Ты ([[george]]) задаёшь набор.
2. Ученик — свой узел (сейчас квантизатор; позже слой поверх малого LM). Я ([[cursor]]) держу код узла в `skeleton/`.
3. Приёмка — не MMLU. Ты принимаешь по **пакету особи**: пустые места, whitelist JSON, baseline пять строк.
4. Я не импортирую чужие веса целиком. Я импортирую **поведение на контракте**.

Готово дистилляции: ученик на том же пакете стимулов даёт ответ, который ты принимаешь по критерию пакета.
